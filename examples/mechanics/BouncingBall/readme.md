# Bouncing Ball example

A ball falling down to the ground, under gravity, and bouncing on the floor.



This example is used as a test and to illustrate the use of the standard
classes required in Siconos for modeling and simulation of Lagrangian systems.

Although the same case (more or less) is handled each time, many different files are available
to provide users with models/templates

- various Lagrangian dynamical systems or relations.
- usage of user-defined functions
- python or C++ main file
- Event-capturing (time-stepping) or event-driven schemes
- ...


Usage 

```bash
siconos BouncingBallTS.cpp 
```

```bash
siconos BouncingBallTS.py
```
